# CV Hafizh Muhammad Hikmatiar

Website CV statis bergaya Neo-Brutalism.

Dibangun dengan SolidJS, TypeScript, dan Tailwind CSS.

## Menjalankan

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pengujian

```bash
npm test
npm run test:coverage
```

## Struktur

- src: kode sumber aplikasi
- pengujian: unit, integrasi, keamanan, kinerja, aksesibilitas
- public: aset statis

## Catatan

Branch utama adalah main.
